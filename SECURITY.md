# Security policy

Please do **not** open a public issue for a vulnerability. Report it privately through
[GitHub Security Advisories](https://github.com/TLecae/Carriole/security/advisories/new).

You will get an answer within a few working days. Only the latest release receives fixes.

Threat model and current measures: [docs/securite.md](docs/securite.md) (French). Reminder: a flow or a plugin is code
run with your permissions; do not open flows from unknown sources.
