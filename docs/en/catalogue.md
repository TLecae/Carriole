### Convert a date — `ConvertDate`

Reads a date written as text (or a timestamp) and converts it: date, date-time, formatted text, Unix seconds.

- **Inputs** : `input` — **Outputs** : `output`, `Rejected` — **Processing** : streaming

### Run a flow — `RunFlow`

Runs another flow for each received feature, with parameters taken from its attributes.

- **Inputs** : `input` — **Outputs** : `Succeeded`, `Failed` — **Processing** : blocking (reads all the data before producing)

Each received feature launches a run of the given flow (`etl run` in a separate process: isolated memory, a crash does not stop the others). "In parallel" sets the number of simultaneous runs. For a folder of files: ListFiles → RunFlow, with the launched flow's parameter linked to the path attribute.

<a id="warpraster"></a>

### Raster reprojection — `WarpRaster`

Changes the coordinate system of a raster, with choice of resolution and resampling.

- **Inputs** : `input` — **Outputs** : `output` — **Processing** : streaming

The raster is recomputed in the "Target system" (EPSG:2154, EPSG:4326…). ### Oracle writer — `OracleWriter`

Writes the features to an Oracle table (created if needed), in a single transaction.

- **Inputs** : `input` — **Outputs** : none — **Processing** : streaming
