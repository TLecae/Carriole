# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be kind and respectful to everyone, whatever their background, identity or experience; no harassment.

Report unacceptable behavior privately to the maintainer through a
[private advisory](https://github.com/TLecae/Carriole/security/advisories/new) or a message on GitHub (@TLecae).
