Process geographic data without writing code

Carriole is a desktop ETL for GIS: modifiers are assembled on a canvas, the flow is run, and every result can be checked on a table and a map.

Build, check, automate

Everything is done with the mouse and forms.

Build

Modifiers are dragged from the palette and connected output to input. Each parameter has its form, with help and a link to the documentation. Expressions and SQL are written with the list of attributes and their values a click away.

Check

A click on a node shows its output on a table (filters, sorting) and a map (colors by attribute, OpenStreetMap or satellite basemap). Before running, warnings point out a missing attribute or parameter.

Automate

Running again only recomputes what changed. A flow can run once per file of a folder or per value, and be scheduled. Flows are files the team shares.

On your computer

  • Installed with an .exe (Windows) or run as an AppImage (Linux); Python, GDAL, DuckDB and the projection grids are included.
  • No server: Carriole reads and writes your files, network shares and databases with your own permissions.
  • Internet is only used for the basemap and for the web sources your flows call.
  • Interface in English and French.
  • Optional AI assistant (Claude, OpenAI, OpenRouter, Ollama): it proposes changes to the flow; what it may read is configurable.

Download

Windows 10 / 11 Carriole-Setup.exe
Installer for all users of the computer. It is not code-signed: on the SmartScreen warning, choose “More info”, then “Run anyway”.
Linux x64 Carriole.AppImage
Make the file executable (chmod +x) and run it. No installation or admin rights needed.
