Vector processing

Your own modifiers, in Python

A modifier is a single Python file. Its parameters become a form in the editor; drop it in the plugins folder and it shows up in the palette.

  • Batches of features as Arrow tables, geometry ready for Shapely
  • Rejected features keep their reason, the run goes on
  • Unit tests with the provided helpers
class SurfaceCalculator(Modifier):
    name = "SurfaceCalculator"
    label = "Surface area"
    category = "Geometry"

    class Params(Params):
        attribute: str = "surface"
        unit: Literal["m2", "ha"] = "m2"  # a drop-down list

    def process(self, batch):
        area = shapely.area(geometries(batch))
        if self.params.unit == "ha":
            area = area / 10_000
        return {"output": batch.append_column(
            self.params.attribute, pa.array(area))}
